# Model artifacts

This folder documents the canonical artifact policy.

The following files are generated by training and are not committed as normal source files:

- resumable base checkpoints: `nyxvault-output/checkpoints/step_N.pt`
- best base weights: `nyxvault-output/checkpoints/best.pt`
- trained tokenizer: `nyxvault-output/tokenizer.json`
- mobile model export: `nyxvault-output/nyxvault.onnx`
- mobile tokenizer: `nyxvault-output/tokenizer_mobile.json`
- SFT checkpoints: `nyxvault-output/sft_checkpoints/sft_step_N.pt` and `best_sft.pt`

Keep the complete `nyxvault-output` folder in Google Drive while training. To place binary model artifacts on GitHub, package them into a ZIP and publish the ZIP as an asset of a GitHub Release with `training/publish_release_assets.py`.

GitHub Release assets are part of this same repository, while avoiding large binary objects in the regular Git history. The repository does not contain the owner's private Colab checkpoint binaries until the owner publishes them from their Colab session.
