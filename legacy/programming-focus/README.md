# Archived programming-focus prototype

This directory preserves the earlier `training/programming-focus` branch's Python CLI and browser prototypes. These files are historical and are not used by the current Android app or Transformer training pipeline.

The branch also contained old generated retrieval/neural artifacts (`model_index.json`, `neural_model.npz`, `training_report.json`) trained from an older knowledge corpus. Those binaries and the old personal knowledge corpus were intentionally not copied into the public active repository. Current training data is under `training/data/`; the current model architecture and trainers are under `training/`.

The workflow file is archived inside this directory and is not an active GitHub Actions workflow.
