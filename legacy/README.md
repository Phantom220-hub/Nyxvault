# Archived NYXVAULT prototypes

This folder preserves earlier AI experiments from branches of this same repository. They are kept for history and comparison, not used by the active Android app or current Transformer training pipeline.

- `neural-integration/`: early Python CLI app with TF-IDF retrieval and a small NumPy character-level MLP.
- `programming-focus/`: later Python CLI/browser prototype with TF-IDF retrieval and a NumPy character-level RNN.

The active implementation lives at the repository root and under `training/`. Do not copy archived workflow files into the root `.github/workflows/` path; they are historical files only.

Old generated retrieval/neural binaries and old personal knowledge corpora from prototype branches were not copied into this public archive. Current curated datasets are under `training/data/`, while model checkpoints generated by Colab are published as Release assets only when the owner chooses to upload them.
