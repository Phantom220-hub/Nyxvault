# Archived NYXVAULT prototypes

This folder preserves earlier AI experiments that existed on branches of the same repository. They are kept for history and comparison, not used by the active Android app or current Transformer training pipeline.

- `neural-integration/`: early Python CLI app with TF-IDF retrieval and a small NumPy character-level MLP.

The active implementation lives at the repository root and under `training/`. Do not enable or copy archived workflow files into the root `.github/workflows/`; they are retained only as historical source.
