# Обучение NYXVAULT с Android — инструкция

## Перед началом
Нужен интернет и аккаунт Kaggle. Обучение выполняется на удалённой GPU Kaggle, не на Samsung A16. Телефон только открывает блокнот и показывает вывод.

## 1. Создать Kaggle
1. Откройте браузер Chrome.
2. Перейдите на https://www.kaggle.com/ и нажмите **Register**.
3. Зарегистрируйтесь или войдите в Google-аккаунт.
4. Если Kaggle попросит подтверждение аккаунта/телефона, выполните его обычным способом. Не отправляйте пароль или коды подтверждения никому.

## 2. Открыть блокнот из GitHub
1. Откройте репозиторий https://github.com/Phantom220-hub/Nyxvault.
2. Переключите ветку на **dev**.
3. Откройте папку **training** и файл **nyxvault_train.ipynb**.
4. Скачайте файл блокнота на телефон через кнопку **Download raw file** (или меню загрузки браузера).
5. Откройте Kaggle → **Code** → **New Notebook**.
6. В меню блокнота выберите **File → Import Notebook** (если меню отличается, используйте загрузку/импорт файла в редакторе Kaggle) и выберите скачанный `.ipynb`.
7. Откройте **Settings** справа. В **Accelerator** выберите **GPU**. Если GPU недоступен, попробуйте позже; CPU-обучение будет очень медленным.
8. Сохраните блокнот кнопкой **Save Version**. В настройках интернета оставьте доступ включённым, чтобы получить данные Wikimedia API и клонировать репозиторий.

## 3. Запуск
1. Нажмите **Run All** (Запустить всё).
2. Блокнот установит зависимости, загрузит исходники из ветки dev, соберёт разрешённые тексты, обучит новый токенизатор и модель.
3. Не закрывайте вкладку, пока идёт обучение. Вывод показывает шаги, train loss и validation loss.
4. Результат появится в папке `nyxvault-output/` в файловой панели Kaggle и будет упакован в `nyxvault-training-output.zip`.

## 4. Если сессия оборвалась
- Kaggle может удалить временные файлы после завершения/прерывания сессии. Поэтому после успешного запуска скачайте ZIP сразу.
- Чекпоинты сохраняются каждые 500 шагов в выходной папке. Скачайте папку/ZIP с чекпоинтами перед закрытием сессии.
- Для продолжения загрузите предыдущий архив в новую Kaggle-сессию и распакуйте в рабочую папку `/kaggle/working/nyxvault-resume`. В ячейке блокнота предусмотрен параметр RESUME_FROM; укажите путь к `step_*.pt` в коде, затем снова нажмите Run All. Это единственная настройка при восстановлении; обычный первый запуск менять не нужно.
- Не рассчитывайте, что Kaggle автоматически сохранит незавершённую сессию.

## 5. Скачать модель
1. После завершения откройте файловую панель справа.
2. Найдите `nyxvault-training-output.zip`.
3. Нажмите меню файла → **Download**.
4. Распакуйте архив на телефоне. Внутри будут `best.pt`, чекпоинты, `tokenizer.json`, метрики, примеры и ONNX-экспорт (если он успешно собрался).

## 6. Вернуть модель в проект
Не загружайте крупный бинарный файл в Git обычным коммитом: это раздует репозиторий и APK.
- Для первой проверки храните архив как Kaggle Output и скачивайте по необходимости.
- Для постоянного хранения можно использовать бесплатный релиз GitHub, если размер файла укладывается в действующие ограничения GitHub Releases. Создайте Release в репозитории и прикрепите архив как asset; затем приложение сможет получить отдельный файл по URL релиза. Не делайте ссылку публичной, если в архиве есть личные данные.
- После публикации модели её SHA-256 и URL добавляются в отдельный manifest приложения. Само подключение модели к Android будет отдельным этапом после проверки формата и качества.

## Важно
Loss/perplexity оценивают предсказание следующего токена, а не истинность фактов. 30 тестовых ответов нужно просмотреть вручную. Не используйте модель как источник медицинских, правовых или иных критически важных решений.
