РАЗДЕЛ 1. ПРОГРАММИРОВАНИЕ: PYTHON
==================================================

Вопрос: Что такое Python?
Ответ: Python — высокоуровневый язык программирования общего назначения. Его создал Гвидо ван Россум, первая версия вышла в 1991 году. Он известен простым и читаемым синтаксисом, поэтому его часто выбирают для обучения, анализа данных, автоматизации, сайтов и машинного обучения.

Вопрос: Что такое переменная в Python?
Ответ: Переменная — это имя, которое указывает на значение. Пример: x = 5. Тип в Python определяется автоматически (динамическая типизация), поэтому потом можно написать x = "привет", и имя x будет указывать уже на строку.

Вопрос: Какие основные типы данных есть в Python?
Ответ: int (целые числа), float (дробные), str (строки), bool (True и False), list (список), tuple (кортеж), dict (словарь), set (множество) и None (отсутствие значения).

Вопрос: Чем список отличается от кортежа?
Ответ: Список (list) можно менять: добавлять, удалять и заменять элементы. Кортеж (tuple) изменить нельзя после создания. Список пишется в квадратных скобках [1, 2, 3], кортеж в круглых (1, 2, 3).

Вопрос: Что такое словарь в Python?
Ответ: Словарь (dict) хранит пары «ключ: значение». Пример: ученик = {"имя": "Али", "возраст": 15}. Значение достают по ключу: ученик["имя"] вернёт "Али". Ключи должны быть уникальными.

Вопрос: Как работает цикл for в Python?
Ответ: Цикл for перебирает элементы последовательности. Пример: for i in range(3): print(i) выведет 0, 1, 2. Функция range(3) создаёт числа от 0 до 2, последнее число не входит.

Вопрос: Как работает цикл while?
Ответ: Цикл while повторяет действия, пока условие истинно. Пример: n = 3, затем while n > 0: print(n); n -= 1 выведет 3, 2, 1. Если условие никогда не станет ложным, цикл будет бесконечным.

Вопрос: Как создать функцию в Python?
Ответ: Через ключевое слово def. Пример: def сумма(a, b): return a + b. Вызов сумма(2, 3) вернёт 5. Слово return возвращает результат из функции.

Вопрос: Для чего нужны отступы в Python?
Ответ: Отступы показывают, какие строки входят в блок (тело цикла, функции, условия). В Python это часть синтаксиса, а не украшение. Обычно используют 4 пробела. Неверный отступ вызывает ошибку IndentationError.

Вопрос: Что такое генератор списков (list comprehension)?
Ответ: Короткий способ создать список. Пример: [x * x for x in range(5)] даст [0, 1, 4, 9, 16]. С условием: [x for x in range(10) if x % 2 == 0] даст чётные числа [0, 2, 4, 6, 8].

Вопрос: Что такое срезы?
Ответ: Срез берёт часть последовательности. Для s = "программа": s[0:3] вернёт "про", s[-1] вернёт последний символ, s[::-1] вернёт строку задом наперёд. Правая граница в срезе не включается.

Вопрос: В чём разница между == и is?
Ответ: Оператор == сравнивает значения, оператор is проверяет, что это один и тот же объект в памяти. Для чисел и строк обычно нужен ==. Оператор is используют в основном для проверки на None: if x is None.

Вопрос: Как в Python обработать ошибку?
Ответ: Через try и except. Пример: try: x = 10 / 0, затем except ZeroDivisionError: print("На ноль делить нельзя"). Код в except выполнится только если в try произошла такая ошибка.

Вопрос: Какие бывают частые ошибки в Python?
Ответ: IndexError — выход за границы списка. KeyError — нет такого ключа в словаре. TypeError — операция с неподходящим типом, например "5" + 3. ZeroDivisionError — деление на ноль. NameError — используется имя, которое не объявлено. SyntaxError — нарушен синтаксис.

Вопрос: Как прочитать файл в Python?
Ответ: Рекомендуемый способ: with open("файл.txt", "r", encoding="utf-8") as f: текст = f.read(). Конструкция with сама закрывает файл. Для записи используют режим "w" (перезапись) или "a" (дописывание).

Вопрос: Что такое класс в Python?
Ответ: Класс — шаблон для создания объектов. Он описывает данные (атрибуты) и действия (методы). Пример: class Собака: def __init__(self, имя): self.имя = имя. Объект создаётся так: d = Собака("Рекс"). Метод __init__ выполняется при создании объекта.

Вопрос: Что такое lambda?
Ответ: Это короткая анонимная функция в одну строку. Пример: квадрат = lambda x: x * x, тогда квадрат(4) вернёт 16. Часто используют с sorted или map.

Вопрос: Как подключить модуль в Python?
Ответ: Командой import. Пример: import math, затем math.sqrt(16) вернёт 4.0. Можно импортировать отдельное: from math import pi. Сторонние библиотеки ставят через pip, например pip install numpy.

Вопрос: Как узнать длину списка или строки?
Ответ: Функцией len(). len([1, 2, 3]) вернёт 3, len("мир") вернёт 3.

Вопрос: Чем отличаются append и extend у списка?
Ответ: append добавляет один элемент в конец. extend добавляет все элементы другой последовательности. Если a = [1, 2], то a.append([3, 4]) даст [1, 2, [3, 4]], а a.extend([3, 4]) даст [1, 2, 3, 4].

Вопрос: Как получить ввод от пользователя в Python?
Ответ: Функцией input(). Она всегда возвращает строку. Для числа её преобразуют: n = int(input("Введите число: ")).

==================================================
РАЗДЕЛ 2. ПРОГРАММИРОВАНИЕ: C++
==================================================

Вопрос: Что такое C++?
Ответ: C++ — компилируемый язык программирования со статической типизацией. Его создал Бьёрн Страуструп; работа началась в 1979 году как «C с классами», название C++ появилось в 1983 году. Язык используют для игр, операционных систем, драйверов и программ, где важна скорость.

Вопрос: Как выглядит простейшая программа на C++?
Ответ: #include <iostream>, затем int main() { std::cout << "Привет, мир!" << std::endl; return 0; }. Функция main — точка входа: с неё начинается выполнение программы.

Вопрос: Как компилируется программа на C++?
Ответ: Сначала препроцессор обрабатывает директивы вроде #include, затем компилятор превращает код в объектные файлы, затем компоновщик (линкер) собирает из них исполняемый файл. Пример команды: g++ main.cpp -o main.

Вопрос: Какие основные типы есть в C++?
Ответ: int (целое, обычно 4 байта), double (дробное с двойной точностью), float, char (символ), bool (true или false), std::string (строка). Размер типов зависит от платформы.

Вопрос: Что такое указатель?
Ответ: Указатель хранит адрес переменной в памяти. Пример: int x = 5; int* p = &x;. Запись *p даёт значение по адресу (5), а &x — адрес переменной x. Неправильная работа с указателями ведёт к ошибкам и утечкам памяти.

Вопрос: Чем ссылка отличается от указателя?
Ответ: Ссылка — это второе имя существующей переменной. Её нужно инициализировать при создании и нельзя переназначить на другой объект. Указатель можно менять и он может быть нулевым (nullptr). Ссылки удобны для передачи больших объектов в функцию без копирования.

Вопрос: Что такое утечка памяти?
Ответ: Это ситуация, когда память выделили (например, через new), но не освободили (delete), и программа теряет к ней доступ. В современном C++ этого избегают с помощью умных указателей std::unique_ptr и std::shared_ptr и принципа RAII.

Вопрос: Что такое RAII?
Ответ: Принцип «получение ресурса — это инициализация». Ресурс (память, файл, соединение) захватывается в конструкторе объекта и освобождается в деструкторе. Благодаря этому ресурс освобождается автоматически, даже если произошла ошибка.

Вопрос: Что такое STL?
Ответ: Стандартная библиотека шаблонов: контейнеры (vector, map, set, list), алгоритмы (sort, find) и итераторы. Например, std::vector<int> v = {3, 1, 2}; std::sort(v.begin(), v.end()); отсортирует вектор по возрастанию.

Вопрос: Чем struct отличается от class в C++?
Ответ: Почти ничем, кроме доступа по умолчанию: в struct члены по умолчанию public (открытые), в class — private (закрытые).

Вопрос: Что такое конструктор и деструктор?
Ответ: Конструктор вызывается при создании объекта и подготавливает его. Деструктор вызывается при уничтожении объекта и освобождает ресурсы. Деструктор называется так же, как класс, с тильдой: ~Класс().

Вопрос: Что такое const?
Ответ: Ключевое слово, которое запрещает менять значение. const int x = 5; нельзя изменить. Константные ссылки const T& используют для безопасной передачи объектов в функции.

Вопрос: Что такое шаблон (template)?
Ответ: Способ писать код, который работает с разными типами. Пример: template <typename T> T максимум(T a, T b) { return a > b ? a : b; }. Эта функция подойдёт и для int, и для double.

Вопрос: Что такое перегрузка функций?
Ответ: Возможность иметь несколько функций с одним именем, но с разными параметрами. Компилятор выбирает нужную версию по типам аргументов.

Вопрос: Для чего нужны заголовочные файлы (.h, .hpp)?
Ответ: В них объявляют функции, классы и константы, чтобы использовать их в нескольких файлах. Подключают директивой #include "файл.h". Чтобы заголовок не подключился дважды, используют #pragma once или include guards.

Вопрос: Чем C++ отличается от C?
Ответ: C++ добавляет классы и объектно-ориентированное программирование, шаблоны, исключения, ссылки, пространства имён и богатую стандартную библиотеку. Он почти совместим с C, но не полностью.

==================================================
РАЗДЕЛ 3. АЛГОРИТМЫ И СТРУКТУРЫ ДАННЫХ
==================================================

Вопрос: Что такое алгоритм?
Ответ: Алгоритм — это конечная последовательность чётких шагов для решения задачи. Хороший алгоритм однозначен (нет двусмысленности), конечен (завершается) и даёт результат для любых допустимых входных данных.

Вопрос: Что такое временная сложность и запись O(n)?
Ответ: Это оценка того, как растёт время работы алгоритма при росте размера входа n. O(1) — не зависит от n; O(log n) — очень медленный рост; O(n) — линейный; O(n log n) — быстрые сортировки; O(n²) — квадратичный, медленный на больших данных; O(2ⁿ) — экспоненциальный, годится только для маленьких n.

Вопрос: Как работает бинарный поиск?
Ответ: Он ищет элемент в отсортированном массиве. Берёт середину; если искомое меньше, продолжает в левой половине, если больше — в правой. Каждый шаг уменьшает область вдвое, поэтому сложность O(log n). В массиве из миллиона элементов нужно около 20 шагов.

Вопрос: Как работает сортировка пузырьком?
Ответ: Проходим по массиву, сравниваем соседние элементы и меняем местами, если они стоят неправильно. Большие элементы «всплывают» в конец. Сложность O(n²), поэтому для больших массивов не подходит, но алгоритм прост для обучения.

Вопрос: Как работает быстрая сортировка (quicksort)?
Ответ: Выбирается опорный элемент. Остальные делятся на меньшие и большие, затем каждая часть сортируется рекурсивно. Средняя сложность O(n log n), в худшем случае O(n²), если опорные элементы выбираются неудачно.

Вопрос: Как работает сортировка слиянием?
Ответ: Массив делится пополам, каждая половина сортируется рекурсивно, затем две отсортированные половины сливаются в одну. Сложность всегда O(n log n), сортировка стабильная, но требует дополнительной памяти.

Вопрос: Что такое рекурсия?
Ответ: Это когда функция вызывает саму себя. Обязательно нужен базовый случай, который останавливает вызовы. Пример: факториал: если n равно 0 или 1, вернуть 1, иначе вернуть n * факториал(n − 1).

Вопрос: Что такое стек и очередь?
Ответ: Стек работает по принципу LIFO (последним пришёл — первым вышел), как стопка тарелок. Очередь работает по принципу FIFO (первым пришёл — первым вышел), как очередь в магазине.

Вопрос: Что такое хеш-таблица?
Ответ: Структура, которая хранит пары «ключ — значение» и по хеш-функции быстро вычисляет, где лежит значение. Поиск, вставка и удаление в среднем занимают O(1). В Python это dict, в C++ это std::unordered_map.

Вопрос: Что такое граф?
Ответ: Это набор вершин, соединённых рёбрами. Графами описывают дороги, соцсети, зависимости между задачами. Рёбра бывают направленными и ненаправленными, с весами и без.

Вопрос: Чем отличаются поиск в ширину (BFS) и в глубину (DFS)?
Ответ: BFS идёт слоями от начальной вершины и использует очередь. Он находит кратчайший путь в графе без весов. DFS уходит как можно глубже по одной ветке и возвращается, использует стек или рекурсию.

Вопрос: Для чего нужен алгоритм Дейкстры?
Ответ: Для поиска кратчайших путей от одной вершины до остальных во взвешенном графе, где веса рёбер неотрицательны. Алгоритм на каждом шаге берёт вершину с наименьшим известным расстоянием и обновляет расстояния до её соседей.

Вопрос: Что такое динамическое программирование?
Ответ: Метод решения задач, когда большая задача разбивается на пересекающиеся подзадачи, а их решения запоминаются, чтобы не считать повторно. Пример: числа Фибоначчи. Без запоминания расчёт экспоненциально долгий, с запоминанием линейный.

Вопрос: Что такое жадный алгоритм?
Ответ: Алгоритм, который на каждом шаге выбирает локально лучший вариант в надежде получить лучшее решение в целом. Он работает не всегда. Пример: выдача сдачи минимальным числом монет работает с обычными номиналами.

Вопрос: Как алгоритм Евклида находит НОД?
Ответ: Нужно повторять замену пары (a, b) на (b, a mod b), пока b не станет 0; тогда ответом будет a. Пример: НОД(48, 18): (48, 18) → (18, 12) → (12, 6) → (6, 0), ответ 6.

Вопрос: Что такое решето Эратосфена?
Ответ: Способ найти все простые числа до n. Выписывают числа от 2 до n, берут наименьшее незачёркнутое, оставляют его и вычёркивают все его кратные. Повторяют, пока не обработают числа до корня из n. Оставшиеся числа простые.

Вопрос: Что такое двоичное дерево?
Ответ: Структура данных, где у каждого узла не более двух потомков (левый и правый). В двоичном дереве поиска все значения слева меньше значения узла, справа больше, что позволяет искать за O(log n) в сбалансированном случае.

Вопрос: Что такое куча (heap)?
Ответ: Двоичное дерево, где родитель всегда не меньше (max-heap) или не больше (min-heap) своих потомков. Позволяет быстро получать наименьший или наибольший элемент. На ней основаны приоритетные очереди и пирамидальная сортировка.

Вопрос: Чем массив отличается от связного списка?
Ответ: В массиве элементы лежат подряд, доступ по индексу за O(1), но вставка в середину дорогая. В связном списке каждый элемент хранит ссылку на следующий; вставка быстрая при известной позиции, но доступ по индексу медленный, O(n).

РАЗДЕЛ 4. МАТЕМАТИКА
==================================================

Вопрос: Как решить квадратное уравнение ax² + bx + c = 0?
Ответ: Найти дискриминант D = b² − 4ac. Если D > 0, два корня: x = (−b ± √D) / (2a). Если D = 0, один корень x = −b / (2a). Если D < 0, действительных корней нет. Пример: x² − 5x + 6 = 0: D = 25 − 24 = 1, корни x = (5 ± 1) / 2, то есть 3 и 2.

Вопрос: Что говорит теорема Пифагора?
Ответ: В прямоугольном треугольнике квадрат гипотенузы равен сумме квадратов катетов: c² = a² + b². Пример: катеты 3 и 4 дают гипотенузу 5, так как 9 + 16 = 25.

Вопрос: Как найти площадь и длину окружности круга?
Ответ: Площадь S = πr², длина окружности L = 2πr, где r — радиус. Число π примерно равно 3,14159. Для r = 2: S ≈ 12,57, L ≈ 12,57.

Вопрос: Как найти процент от числа?
Ответ: Нужно умножить число на процент и разделить на 100. Пример: 15% от 200 = 200 × 15 / 100 = 30. Чтобы найти, сколько процентов составляет a от b, считают a / b × 100.

Вопрос: Что такое простое число?
Ответ: Натуральное число больше 1, которое делится только на 1 и на само себя. Первые простые числа: 2, 3, 5, 7, 11, 13, 17, 19. Число 2 — единственное чётное простое. Число 1 не считается простым.

Вопрос: Что такое НОД и НОК?
Ответ: НОД — наибольший общий делитель, НОК — наименьшее общее кратное. Для 12 и 18: НОД = 6, НОК = 36. Связь: НОД(a, b) × НОК(a, b) = a × b.

Вопрос: Как найти сумму арифметической прогрессии?
Ответ: S = n(a₁ + aₙ) / 2, где n — число членов. Пример: сумма чисел от 1 до 100 равна 100 × (1 + 100) / 2 = 5050.

Вопрос: Что такое геометрическая прогрессия?
Ответ: Последовательность, где каждый следующий член получается умножением предыдущего на число q (знаменатель). Пример: 2, 6, 18, 54, q = 3. Член номер n равен b₁ × qⁿ⁻¹.

Вопрос: Что такое логарифм?
Ответ: Логарифм числа b по основанию a — это показатель степени x, в которую нужно возвести a, чтобы получить b: logₐ b = x, если aˣ = b. Пример: log₂ 8 = 3, так как 2³ = 8; log₁₀ 1000 = 3.

Вопрос: Какие основные тригонометрические тождества нужно знать?
Ответ: sin²α + cos²α = 1; tg α = sin α / cos α. Значения: sin 30° = 1/2, cos 60° = 1/2, sin 90° = 1, cos 0° = 1, sin 45° = √2/2.

Вопрос: Какие формулы сокращённого умножения существуют?
Ответ: (a + b)² = a² + 2ab + b²; (a − b)² = a² − 2ab + b²; a² − b² = (a − b)(a + b). Пример: 101² = 100² + 2×100 + 1 = 10201.

Вопрос: Как посчитать вероятность?
Ответ: Вероятность события равна числу благоприятных исходов, делённому на число всех равновозможных исходов. Монета: вероятность орла 1/2. Кубик: вероятность выпадения шестёрки 1/6, чётного числа 3/6 = 1/2.

Вопрос: Чем отличаются среднее, медиана и мода?
Ответ: Среднее арифметическое — сумма значений, делённая на их количество. Медиана — значение в середине упорядоченного ряда. Мода — самое часто встречающееся значение. Для ряда 1, 2, 2, 3, 12: среднее 4, медиана 2, мода 2. Медиана устойчива к выбросам.

Вопрос: Как решить линейное уравнение?
Ответ: Нужно перенести слагаемые с x в одну сторону, числа в другую и разделить на коэффициент. Пример: 3x + 5 = 20 → 3x = 15 → x = 5. Проверка: 3×5 + 5 = 20.

Вопрос: Как решить систему двух линейных уравнений?
Ответ: Способом подстановки или сложения. Пример: x + y = 5 и x − y = 1. Складываем: 2x = 6, x = 3, затем y = 2. Проверка: 3 + 2 = 5 и 3 − 2 = 1.

Вопрос: Что такое факториал?
Ответ: Факториал n! — произведение всех натуральных чисел от 1 до n. 5! = 1×2×3×4×5 = 120. По определению 0! = 1.

Вопрос: Что такое сочетания в комбинаторике?
Ответ: Число способов выбрать k элементов из n без учёта порядка: C(n, k) = n! / (k!(n − k)!). Пример: сколько способов выбрать 2 человека из 5: C(5, 2) = 10.

Вопрос: Чему равна сумма углов треугольника?
Ответ: 180°. Сумма углов выпуклого четырёхугольника 360°. Для многоугольника с n сторонами сумма углов равна (n − 2) × 180°.

Вопрос: Как найти площадь треугольника?
Ответ: S = (1/2) × основание × высота. Пример: основание 6, высота 4: S = 12. Также можно использовать формулу Герона по трём сторонам.

Вопрос: Как найти объём шара и цилиндра?
Ответ: Объём шара V = (4/3)πr³. Объём цилиндра V = πr²h, где h — высота.

Вопрос: Чему равна производная степенной функции?
Ответ: Производная xⁿ равна n·xⁿ⁻¹. Пример: производная x³ равна 3x². Производная sin x равна cos x, производная eˣ равна eˣ, производная константы равна 0.

Вопрос: Что такое интеграл?
Ответ: Интеграл — обратная производной операция и способ находить площади под графиком. Неопределённый интеграл от xⁿ равен xⁿ⁺¹ / (n + 1) + C при n ≠ −1. Пример: интеграл от x² равен x³/3 + C.

Вопрос: Можно ли делить на ноль?
Ответ: Нет, деление на ноль не определено. Если бы 5/0 = x, то x · 0 = 5, но любое число, умноженное на ноль, даёт ноль.

Вопрос: Что такое иррациональные числа?
Ответ: Числа, которые нельзя записать в виде дроби p/q с целыми p и q. Их десятичная запись бесконечна и непериодична. Примеры: √2, π, e.

Вопрос: Что такое мнимая единица?
Ответ: Число i, такое что i² = −1. Комплексные числа записываются как a + bi. Они позволяют решать уравнения вроде x² + 1 = 0, у которых нет действительных корней.

Вопрос: Как связаны скорость, время и путь?
Ответ: Путь = скорость × время, то есть s = v·t. Отсюда v = s / t и t = s / v. Пример: 60 км/ч за 2,5 часа дают 150 км.

Вопрос: Как перевести обыкновенную дробь в десятичную?
Ответ: Нужно разделить числитель на знаменатель. 3/4 = 0,75; 1/3 = 0,333... (периодическая дробь). Чтобы сложить дроби, приводят их к общему знаменателю: 1/2 + 1/3 = 3/6 + 2/6 = 5/6.

==================================================
РАЗДЕЛ 5. ФИЗИКА
==================================================

Вопрос: Какие три закона Ньютона описывают движение?
Ответ: Первый закон (инерции): тело сохраняет покой или равномерное прямолинейное движение, пока на него не действуют другие силы. Второй закон: ускорение прямо пропорционально силе и обратно пропорционально массе, F = ma. Третий закон: силы взаимодействия двух тел равны по величине и противоположны по направлению.

Вопрос: Чему равна скорость света?
Ответ: В вакууме скорость света равна 299 792 458 м/с, это примерно 300 000 км/с. Свет проходит расстояние от Солнца до Земли примерно за 8 минут 20 секунд.

Вопрос: Чему равно ускорение свободного падения?
Ответ: Около 9,8 м/с² у поверхности Земли (часто для расчётов берут 10 м/с²). В вакууме все тела падают с одним и тем же ускорением независимо от массы.

Вопрос: Чем отличаются масса и вес?
Ответ: Масса — мера количества вещества и инертности тела, измеряется в килограммах и не зависит от места. Вес — сила, с которой тело давит на опору или тянет подвес, P = mg, измеряется в ньютонах. На Луне вес меньше, масса та же.

Вопрос: Как рассчитать плотность и давление?
Ответ: Плотность ρ = m / V (масса, делённая на объём), единица кг/м³. Давление p = F / S (сила, делённая на площадь), единица паскаль (Па). Чем меньше площадь опоры при той же силе, тем больше давление, поэтому нож острый.

Вопрос: Что такое работа и мощность?
Ответ: Механическая работа A = F · s (сила, умноженная на путь вдоль силы), единица джоуль (Дж). Мощность P = A / t, единица ватт (Вт). 1 Вт = 1 Дж/с.

Вопрос: По каким формулам считают кинетическую и потенциальную энергию?
Ответ: Кинетическая энергия Eк = mv² / 2. Потенциальная энергия поднятого тела Eп = mgh. В замкнутой системе без трения полная механическая энергия сохраняется.

Вопрос: Что говорит закон Ома?
Ответ: Для участка цепи сила тока равна напряжению, делённому на сопротивление: I = U / R. Ток измеряют в амперах, напряжение в вольтах, сопротивление в омах. Мощность тока P = U · I.

Вопрос: Что говорит закон всемирного тяготения?
Ответ: Два тела притягиваются с силой F = G · m₁ · m₂ / r², где r — расстояние между центрами тел, G — гравитационная постоянная (примерно 6,67·10⁻¹¹ Н·м²/кг²). Сила растёт с массами и быстро уменьшается с расстоянием.

Вопрос: Чему равен абсолютный ноль температуры?
Ответ: −273,15 °C, это 0 кельвинов. Перевод: T(K) = t(°C) + 273,15. Температура воды 0 °C равна 273,15 К. При абсолютном нуле тепловое движение частиц минимально.

Вопрос: Какова скорость звука?
Ответ: В воздухе при 20 °C примерно 343 м/с. В воде звук идёт быстрее (около 1480 м/с), в стали ещё быстрее. В вакууме звук не распространяется, нужна среда.

Вопрос: Что означает формула E = mc²?
Ответ: Это формула Эйнштейна о связи массы и энергии: энергия покоя тела равна его массе, умноженной на квадрат скорости света. Маленькая масса соответствует огромной энергии, это лежит в основе ядерной энергетики.

Вопрос: Как связаны длина волны, частота и скорость?
Ответ: v = λ · f, то есть скорость волны равна длине волны, умноженной на частоту. Частоту измеряют в герцах (Гц): 1 Гц — одно колебание в секунду.

Вопрос: Что такое закон Архимеда?
Ответ: На тело, погружённое в жидкость или газ, действует выталкивающая сила, равная весу вытесненной жидкости: F = ρ · g · V. Тело плавает, если выталкивающая сила не меньше его веса, то есть если его средняя плотность не больше плотности жидкости.

Вопрос: Как устроен атом?
Ответ: В центре атома ядро из протонов (положительный заряд) и нейтронов (без заряда). Вокруг ядра находятся электроны (отрицательный заряд). В нейтральном атоме число протонов равно числу электронов.

Вопрос: Какие бывают виды теплопередачи?
Ответ: Теплопроводность (передача тепла при контакте, например нагрев ложки в горячем чае), конвекция (перенос тепла потоками жидкости или газа) и излучение (передача тепла электромагнитными волнами, так Солнце греет Землю).

Вопрос: Чему равно нормальное атмосферное давление?
Ответ: 101 325 Па, это 760 мм ртутного столба или около 1 атмосферы. С высотой давление уменьшается.

Вопрос: Какие основные единицы СИ существуют?
Ответ: Метр (длина), килограмм (масса), секунда (время), ампер (сила тока), кельвин (температура), моль (количество вещества), кандела (сила света).

Вопрос: Что такое первая космическая скорость?
Ответ: Минимальная скорость, при которой тело становится спутником Земли и движется по круговой орбите у поверхности. Она примерно равна 7,9 км/с. Вторая космическая скорость, около 11,2 км/с, позволяет покинуть Землю.

Вопрос: Почему появляется радуга?
Ответ: Белый солнечный свет состоит из лучей разных цветов. В каплях воды он преломляется, отражается от задней стенки капли и снова преломляется. Лучи разных цветов отклоняются на разные углы (дисперсия), поэтому свет раскладывается в спектр.

Вопрос: Что говорит закон Гука?
Ответ: При малых деформациях сила упругости пропорциональна удлинению пружины: F = k · x, где k — жёсткость пружины, x — её удлинение.

Вопрос: Что такое электромагнитная индукция?
Ответ: Явление возникновения электрического тока в замкнутом контуре при изменении магнитного потока через него. Его открыл Майкл Фарадей в 1831 году. На нём основаны генераторы электростанций и трансформаторы.

==================================================
РАЗДЕЛ 6. ХИМИЯ
==================================================

Вопрос: Что такое атом, молекула и химический элемент?
Ответ: Атом — мельчайшая частица химического элемента, сохраняющая его свойства. Молекула — группа атомов, соединённых химическими связями (например, H₂O). Химический элемент — вид атомов с одинаковым зарядом ядра.

Вопрос: Кто создал периодическую таблицу и по какому принципу она устроена?
Ответ: Периодический закон открыл Дмитрий Менделеев в 1869 году. Элементы расположены по возрастанию заряда ядра (атомного номера). Горизонтальные ряды называются периодами, вертикальные столбцы группами; элементы одной группы имеют похожие свойства.

Вопрос: Какие номера и символы у распространённых элементов?
Ответ: Водород H (1), гелий He (2), углерод C (6), азот N (7), кислород O (8), натрий Na (11), алюминий Al (13), хлор Cl (17), калий K (19), кальций Ca (20), железо Fe (26), медь Cu (29), серебро Ag (47), золото Au (79), свинец Pb (82).

Вопрос: Каков состав воды и углекислого газа?
Ответ: Вода H₂O: два атома водорода и один кислорода. Углекислый газ CO₂: один атом углерода и два кислорода. Поваренная соль NaCl состоит из ионов натрия и хлора.

Вопрос: Какие бывают химические связи?
Ответ: Ковалентная (атомы делят общие электронные пары, например в H₂O), ионная (передача электрона от одного атома другому и притяжение ионов, например в NaCl) и металлическая (общее «облако» электронов в металлах).

Вопрос: Что показывает шкала pH?
Ответ: Кислотность раствора. pH меньше 7 — кислая среда, pH равен 7 — нейтральная, pH больше 7 — щелочная. Чистая вода при 25 °C имеет pH около 7. Лимонный сок кислый (pH около 2), мыло щелочное.

Вопрос: Какие вещества называются кислотами, основаниями и солями?
Ответ: Кислоты отдают в растворе ионы водорода (HCl — соляная, H₂SO₄ — серная, HNO₃ — азотная). Основания (щёлочи) дают гидроксид-ионы (NaOH, KOH). Соли состоят из катиона металла и аниона кислотного остатка (NaCl, CaCO₃).

Вопрос: Что такое реакция нейтрализации?
Ответ: Реакция кислоты с основанием, в которой образуются соль и вода. Пример: HCl + NaOH → NaCl + H₂O.

Вопрос: Сформулируй закон сохранения массы.
Ответ: Масса веществ, вступивших в реакцию, равна массе веществ, образовавшихся в результате. Атомы не исчезают, а перегруппировываются. Поэтому в уравнениях реакций число атомов каждого элемента слева и справа должно совпадать.

Вопрос: Как составить уравнение горения водорода?
Ответ: Водород соединяется с кислородом, образуя воду: 2H₂ + O₂ → 2H₂O. Коэффициенты уравнивают число атомов: слева 4 атома H и 2 атома O, справа столько же.

Вопрос: Что такое моль и число Авогадро?
Ответ: Моль — количество вещества, содержащее 6,022·10²³ частиц (число Авогадро). Молярная масса — масса одного моля. Для воды она примерно 18 г/моль (2×1 + 16).

Вопрос: Что такое благородные газы?
Ответ: Элементы 18-й группы: гелий, неон, аргон, криптон, ксенон, радон. Их внешняя электронная оболочка заполнена, поэтому они почти не вступают в химические реакции.

Вопрос: Что такое ржавчина?
Ответ: Это продукт окисления железа в присутствии кислорода и влаги, в основном оксиды и гидроксиды железа. Ржавление разрушает металл. От него защищают покраской, оцинковкой, нержавеющими сплавами.

Вопрос: Что такое катализатор?
Ответ: Вещество, которое ускоряет химическую реакцию, но само в итоге не расходуется. Примеры: платина в каталитических нейтрализаторах автомобилей, ферменты в живых организмах.

Вопрос: Что такое изотопы?
Ответ: Атомы одного элемента с одинаковым числом протонов, но разным числом нейтронов. Пример: углерод-12 и углерод-14. Углерод-14 радиоактивен и используется для датировки находок.

Вопрос: Что такое органическая химия?
Ответ: Химия соединений углерода. Простейший углеводород — метан CH₄ (основа природного газа). Углерод образует длинные цепи и кольца, поэтому органических соединений огромное количество: жиры, белки, углеводы, пластмассы.

Вопрос: Как записывается уравнение фотосинтеза?
Ответ: 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂ на свету, в присутствии хлорофилла. Из углекислого газа и воды растение образует глюкозу и выделяет кислород.

Вопрос: Что происходит при электролизе воды?
Ответ: Под действием постоянного тока вода разлагается на водород и кислород: 2H₂O → 2H₂ + O₂. Водорода получается по объёму вдвое больше, чем кислорода.

Вопрос: Что такое валентность?
Ответ: Число связей, которые атом элемента может образовать с другими атомами. Водород одновалентен, кислород в большинстве соединений двухвалентен, углерод в органических соединениях четырёхвалентен.

Вопрос: Какие бывают агрегатные состояния вещества?
Ответ: Твёрдое, жидкое и газообразное; также существует плазма. Переходы: плавление (твёрдое в жидкое), кристаллизация, испарение, конденсация, сублимация (твёрдое сразу в газ) и десублимация.

Вопрос: Что такое оксиды?
Ответ: Соединения двух элементов, один из которых кислород. Примеры: CO₂, H₂O, Fe₂O₃, SiO₂ (песок). Оксиды металлов обычно основные, оксиды неметаллов обычно кислотные.

==================================================
РАЗДЕЛ 7. БИОЛОГИЯ
==================================================

Вопрос: Что такое клетка?
Ответ: Клетка — основная структурная и функциональная единица живых организмов. Клетки бывают прокариотические (без оформленного ядра, например бактерии) и эукариотические (с ядром: у растений, животных, грибов).

Вопрос: Какие основные части есть у клетки?
Ответ: Мембрана ограничивает клетку и регулирует обмен веществ. Ядро хранит ДНК. Цитоплазма заполняет клетку. Митохондрии вырабатывают энергию (АТФ). Рибосомы синтезируют белки. У растений есть клеточная стенка и хлоропласты.

Вопрос: Что такое ДНК?
Ответ: Дезоксирибонуклеиновая кислота — молекула, которая хранит наследственную информацию. Она имеет форму двойной спирали (описана в 1953 году Уотсоном и Криком, при ключевом вкладе данных Розалинд Франклин). Состоит из нуклеотидов с основаниями A, T, G, C: A соединяется с T, G с C.

Вопрос: Что такое ген?
Ответ: Участок ДНК, содержащий информацию о строении белка или молекулы РНК. Совокупность всех генов организма называется геномом.

Вопрос: Как работает фотосинтез?
Ответ: Растения, водоросли и некоторые бактерии используют энергию света, воду и углекислый газ, чтобы создавать органические вещества (глюкозу) и выделять кислород. Происходит в хлоропластах при участии хлорофилла.

Вопрос: Что такое клеточное дыхание?
Ответ: Процесс, при котором клетка получает энергию из питательных веществ (например, глюкозы) с участием кислорода. Основная часть энергии запасается в виде АТФ в митохондриях. Итог: глюкоза + кислород дают углекислый газ, воду и энергию.

Вопрос: Кто такой Чарльз Дарвин и в чём суть его теории?
Ответ: Английский естествоиспытатель, автор книги «Происхождение видов» (1859). Суть теории эволюции естественным отбором: особи различаются, часть признаков наследуется, выживают и оставляют потомство те, чьи признаки лучше подходят к условиям среды, и со временем признаки в популяции меняются.

Вопрос: Как классифицируют живые организмы?
Ответ: Иерархия: домен, царство, тип (отдел), класс, отряд (порядок), семейство, род, вид. Пример для человека: царство Животные, тип Хордовые, класс Млекопитающие, отряд Приматы, семейство Гоминиды, род Homo, вид Homo sapiens.

Вопрос: Сколько хромосом у человека?
Ответ: 46 хромосом, то есть 23 пары. Одна пара — половые хромосомы (XX у женщин, XY у мужчин).

Вопрос: Как устроено сердце человека?
Ответ: Четырёхкамерное: два предсердия и два желудочка. Правая половина гонит кровь в лёгкие, левая в остальное тело. Клапаны не дают крови течь назад. Сердце взрослого человека в покое сокращается примерно 60–100 раз в минуту.

Вопрос: Из чего состоит кровь?
Ответ: Из плазмы и клеток: эритроцитов (переносят кислород с помощью гемоглобина), лейкоцитов (защита от инфекций) и тромбоцитов (свёртывание крови). Группы крови по системе AB0: I (0), II (A), III (B), IV (AB), плюс резус-фактор.

Вопрос: Сколько костей у взрослого человека?
Ответ: 206. У новорождённых костей больше, часть из них позже срастается.

Вопрос: Чем вирусы отличаются от бактерий?
Ответ: Бактерии — одноклеточные организмы, которые могут размножаться самостоятельно; многие полезны, часть вызывает болезни. Вирусы намного меньше, не имеют клеточного строения и размножаются только внутри чужих клеток. Антибиотики действуют на бактерии и не действуют на вирусы.

Вопрос: Кто такой Грегор Мендель?
Ответ: Австрийский монах и учёный, который в 1860-х годах на опытах с горохом открыл основные законы наследственности: единообразие гибридов первого поколения, расщепление признаков и независимое наследование.

Вопрос: Что такое митоз и мейоз?
Ответ: Митоз — деление клетки, при котором получаются две клетки с тем же набором хромосом, что у материнской (рост, обновление тканей). Мейоз — деление, при котором образуются половые клетки с вдвое меньшим числом хромосом.

Вопрос: Что такое белки и ферменты?
Ответ: Белки — полимеры, построенные из аминокислот (в белках встречается 20 стандартных аминокислот). Они выполняют строительную, защитную, транспортную и другие функции. Ферменты — белки-катализаторы, ускоряющие химические реакции в организме, например амилаза слюны расщепляет крахмал.

Вопрос: Что такое экосистема и пищевая цепь?
Ответ: Экосистема — сообщество живых организмов вместе со средой обитания и связями между ними. Пищевая цепь показывает передачу энергии: продуценты (растения), консументы (животные), редуценты (грибы, бактерии разлагают остатки). Пример: трава → заяц → лиса.

Вопрос: Как работает иммунитет и зачем нужны вакцины?
Ответ: Иммунная система распознаёт и уничтожает чужеродные агенты. Вакцина содержит обезвреженный возбудитель или его часть, и организм вырабатывает защиту (антитела и клетки памяти) без тяжёлой болезни. Вопросы лечения и прививок нужно решать с врачом.

Вопрос: Из чего состоит нервная система?
Ответ: Из головного и спинного мозга (центральная часть) и нервов (периферическая часть). Основная клетка — нейрон, который передаёт сигналы электрическими импульсами и химическими веществами (нейромедиаторами) в местах контакта, синапсах.

Вопрос: Для чего растениям устьица?
Ответ: Это маленькие отверстия на листьях, через которые растение берёт углекислый газ, выделяет кислород и испаряет воду. Их открывают и закрывают замыкающие клетки.

Вопрос: Какую роль играют витамины?
Ответ: Это органические вещества, которые организму нужны в малых количествах для нормального обмена веществ. Большинство не синтезируется организмом и поступает с пищей. Например, витамин C есть в цитрусовых и овощах, витамин D образуется в коже под действием солнечного света.

Вопрос: Кто такие млекопитающие?
Ответ: Класс позвоночных животных, детёныши которых вскармливаются молоком. Для них характерны шерсть или волосы, тёплокровность и, как правило, живорождение. Примеры: человек, кошка, кит, летучая мышь.

РАЗДЕЛ 8. ИСТОРИЯ
==================================================

Вопрос: Когда шла Вторая мировая война?
Ответ: С 1 сентября 1939 года (нападение Германии на Польшу) до 2 сентября 1945 года (капитуляция Японии). В Европе война закончилась в мае 1945 года; в СССР и странах бывшего СССР 9 Мая отмечают День Победы.

Вопрос: Когда шла Первая мировая война?
Ответ: С 1914 по 1918 год. Поводом стало убийство наследника австро-венгерского престола Франца Фердинанда в Сараево. Война закончилась капитуляцией Германии 11 ноября 1918 года.

Вопрос: Когда Колумб достиг Америки?
Ответ: В 1492 году (12 октября) экспедиция Христофора Колумба, искавшая морской путь в Индию, высадилась на островах Карибского моря.

Вопрос: Когда началась Великая французская революция?
Ответ: В 1789 году, штурмом Бастилии 14 июля. Она упразднила монархию и принесла «Декларацию прав человека и гражданина».

Вопрос: Когда пал Константинополь?
Ответ: 29 мая 1453 года, город взяли османские войска султана Мехмеда II. Это событие считается концом Византийской империи.

Вопрос: Когда распался СССР?
Ответ: В декабре 1991 года. 8 декабря было подписано Беловежское соглашение, а 25–26 декабря СССР формально прекратил существование. Таджикистан объявил независимость 9 сентября 1991 года.

Вопрос: Кто первым полетел в космос?
Ответ: Юрий Гагарин, 12 апреля 1961 года на корабле «Восток-1». Полёт длился около 108 минут. Первой женщиной в космосе стала Валентина Терешкова в 1963 году.

Вопрос: Когда люди впервые высадились на Луне?
Ответ: 20 июля 1969 года, экипаж «Аполлона-11». Нил Армстронг первым ступил на поверхность Луны, следом за ним вышел Базз Олдрин.

Вопрос: Что такое Великий шёлковый путь?
Ответ: Система торговых маршрутов между Китаем, Средней Азией, Ближним Востоком и Европой. По нему везли шёлк, пряности, бумагу, драгоценности, а вместе с товарами распространялись идеи, религии и технологии. Важными городами были Самарканд, Бухара, Хорезм, Мерв и Худжанд.

Вопрос: Кто такой Исмаил Самани?
Ответ: Основатель государства Саманидов в Средней Азии и Хорасане, правил около 892–907 годов. Столицей стала Бухара. При Саманидах расцвели наука, поэзия и персидский язык, а Рудаки и другие деятели создали основы персидско-таджикской литературы. Исмоили Сомони — национальный символ Таджикистана.

Вопрос: Кто такой Рудаки?
Ответ: Абу Абдуллах Рудаки (около 858–941) — поэт, которого называют основоположником персидско-таджикской классической литературы. Он родился в селении Панджруд, в нынешнем Таджикистане, и служил при дворе Саманидов.

Вопрос: Кто такой Ибн Сина (Авиценна)?
Ответ: Учёный и врач (980–1037), родился близ Бухары. Автор «Канона врачебной науки», который много веков использовали как учебник медицины в Азии и Европе. Писал также по философии, математике и астрономии.

Вопрос: Когда жил Александр Македонский?
Ответ: 356–323 годы до н. э. Он стал царём Македонии в 336 году до н. э. и создал огромную державу от Греции до Индии. Его походы дошли до Средней Азии, включая территорию нынешнего Таджикистана (например, основание Александрии Эсхаты на месте Худжанда).

Вопрос: Когда пала Западная Римская империя?
Ответ: В 476 году, когда германский вождь Одоакр низложил последнего императора Ромула Августула. Восточная часть (Византия) просуществовала до 1453 года.

Вопрос: Когда построены пирамиды в Гизе?
Ответ: Примерно в 2600–2500 годах до н. э., при фараонах Древнего царства. Самая большая, пирамида Хеопса, была высочайшим сооружением мира около 3800 лет.

Вопрос: Кем был Чингисхан и когда создана Монгольская империя?
Ответ: Темуджин был провозглашён Чингисханом в 1206 году. Его потомки создали крупнейшую сплошную сухопутную империю в истории. Монголы разорили многие города Средней Азии в 1219–1221 годах.

Вопрос: Кто изобрёл книгопечатание в Европе?
Ответ: Иоганн Гутенберг около 1450 года в Майнце создал печатный станок с подвижными литерами. Это ускорило распространение книг и грамотности.

Вопрос: Когда стояла Берлинская стена?
Ответ: С 1961 по 1989 год. Она разделяла Восточный и Западный Берлин. Её падение 9 ноября 1989 года стало символом конца холодной войны и привело к объединению Германии в 1990 году.

Вопрос: Что такое гражданская война в Таджикистане?
Ответ: Внутренний вооружённый конфликт 1992–1997 годов, начавшийся после распада СССР. Он закончился подписанием Общего соглашения о установлении мира и национального согласия 27 июня 1997 года. День национального единства отмечается 27 июня.

==================================================
РАЗДЕЛ 9. ГЕОГРАФИЯ
==================================================

Вопрос: Сколько континентов на Земле?
Ответ: Обычно выделяют шесть или семь континентов: Евразия (или отдельно Европа и Азия), Африка, Северная Америка, Южная Америка, Антарктида и Австралия. В разных странах схема отличается.

Вопрос: Какие существуют океаны?
Ответ: Тихий (самый большой и глубокий), Атлантический, Индийский и Северный Ледовитый. Некоторые учёные выделяют ещё Южный океан вокруг Антарктиды.

Вопрос: Какая самая высокая гора мира?
Ответ: Эверест (Джомолунгма) в Гималаях, высота около 8849 метров над уровнем моря.

Вопрос: Какая самая большая страна мира по площади?
Ответ: Россия, около 17,1 млн км². Далее идут Канада, Китай и США (порядок двух последних зависит от способа подсчёта).

Вопрос: Какая самая длинная река мира?
Ответ: Это спорный вопрос. Традиционно называют Нил (около 6650 км), но по некоторым измерениям с учётом истока длиннее Амазонка. Самая полноводная река мира — Амазонка.

Вопрос: Какая столица у Таджикистана и какие в нём крупные города?
Ответ: Столица — Душанбе. Крупные города: Худжанд (на севере, Согдийская область), Бохтар (бывший Курган-Тюбе), Куляб, Истаравшан, Исфара. Горно-Бадахшанская автономная область расположена на Памире.

Вопрос: С какими странами граничит Таджикистан?
Ответ: С Узбекистаном (запад и север), Кыргызстаном (север), Китаем (восток) и Афганистаном (юг). Выхода к морю страна не имеет.

Вопрос: Какие горы и вершины есть в Таджикистане?
Ответ: Более 90 процентов территории занимают горы: Памир, Гиссаро-Алай, Алайский хребет. Высшая точка страны — пик Исмоили Сомони (7495 м), раньше он назывался пиком Коммунизма. Второй по высоте — пик Ленина (7134 м) на границе с Кыргызстаном.

Вопрос: Какие реки и озера есть в Таджикистане?
Ответ: Реки Пяндж (граничит с Афганистаном, в дальнейшем соединяется с Вахшем и образует Амударью), Вахш, Зеравшан, Сырдарья на севере страны. Озёра: Каракуль, Сарезское озеро (образовалось в 1911 году после обвала), Искандеркуль.

Вопрос: Что такое Нурекская ГЭС?
Ответ: Гидроэлектростанция на реке Вахш, построенная в советское время. Плотина высотой около 300 метров — одна из самых высоких в мире. Станция вырабатывает значительную часть электроэнергии Таджикистана.

Вопрос: Какая валюта в Таджикистане и какой там язык?
Ответ: Валюта — сомони (код TJS). Государственный язык — таджикский; русский язык по Конституции называется языком межнационального общения. Население страны около 10 миллионов человек.

Вопрос: Когда отмечают Навруз?
Ответ: Навруз — праздник весеннего равноденствия и нового года по персидскому календарю, отмечается 21 марта (в разные годы 20–21 марта). Его празднуют в Таджикистане, Иране, Афганистане, Узбекистане, Азербайджане и других странах.

Вопрос: Назови столицы некоторых соседних стран.
Ответ: Узбекистан — Ташкент, Кыргызстан — Бишкек, Туркменистан — Ашхабад, Казахстан — Астана, Афганистан — Кабул, Иран — Тегеран, Китай — Пекин, Россия — Москва.

Вопрос: Назови столицы нескольких стран мира.
Ответ: Франция — Париж, Германия — Берлин, Великобритания — Лондон, Япония — Токио, США — Вашингтон, Индия — Нью-Дели, Турция — Анкара, Египет — Каир, Бразилия — Бразилиа, Австралия — Канберра.

Вопрос: Какая страна самая населённая?
Ответ: По оценкам ООН, с 2023 года самая населённая страна — Индия, на втором месте Китай. Население мира превышает 8 миллиардов человек.

Вопрос: Что такое широта и долгота?
Ответ: Широта показывает положение к северу или югу от экватора (от 0° до 90°). Долгота показывает положение к востоку или западу от нулевого (Гринвичского) меридиана (от 0° до 180°). Вместе они задают точку на Земле.

Вопрос: Почему сменяются времена года?
Ответ: Из-за наклона земной оси (около 23,4°) к плоскости орбиты. Когда Северное полушарие наклонено к Солнцу, там лето, а в Южном зима. Расстояние до Солнца на смену сезонов почти не влияет.

==================================================
РАЗДЕЛ 10. ИСКУССТВЕННЫЙ ИНТЕЛЛЕКТ
==================================================

Вопрос: Что такое искусственный интеллект?
Ответ: Область информатики, цель которой — создавать системы, выполняющие задачи, обычно требующие человеческого интеллекта: распознавание речи и изображений, перевод, игра, планирование, ответы на вопросы. Сегодняшние системы решают конкретные задачи и не обладают сознанием.

Вопрос: Чем машинное обучение отличается от обычного программирования?
Ответ: В обычной программе человек пишет правила. В машинном обучении алгоритм сам находит закономерности в данных и по ним делает предсказания. Качество зависит от данных: чем они точнее и разнообразнее, тем лучше результат.

Вопрос: Какие виды машинного обучения бывают?
Ответ: Обучение с учителем (есть правильные ответы, например «письмо спам или нет»), без учителя (поиск структуры в данных без готовых ответов, например кластеризация) и с подкреплением (агент учится методом проб и наград, как в играх).

Вопрос: Что такое нейронная сеть?
Ответ: Математическая модель из слоёв искусственных нейронов. Каждый нейрон берёт входные числа, умножает на веса, суммирует и пропускает через функцию активации. Обучение подбирает веса, чтобы ошибка на примерах была минимальной.

Вопрос: Что такое глубокое обучение?
Ответ: Раздел машинного обучения с многослойными нейронными сетями. Оно позволило прорывы в распознавании образов, речи и текста. Заметным моментом стала победа сети AlexNet в конкурсе ImageNet в 2012 году.

Вопрос: Как обучается нейронная сеть?
Ответ: Сеть делает предсказание, функция потерь оценивает ошибку, затем метод обратного распространения ошибки считает, как изменить каждый вес, а градиентный спуск немного сдвигает веса в нужную сторону. Шаги повторяют на множестве примеров много раз.

Вопрос: Что такое переобучение?
Ответ: Ситуация, когда модель слишком хорошо запомнила обучающие примеры, но плохо работает на новых данных. Для контроля данные делят на обучающую, проверочную и тестовую выборки. Помогают больше данных, регуляризация, остановка обучения вовремя.

Вопрос: Что такое большая языковая модель (LLM)?
Ответ: Нейросеть, обученная на огромных объёмах текста предсказывать следующий токен. Благодаря этому она умеет вести диалог, переводить, писать текст и код. Она не хранит факты как база данных и может ошибаться, поэтому ответы нужно проверять.

Вопрос: Что такое токен?
Ответ: Единица текста, с которой работает модель: слово, часть слова или символ. Текст разбивается на токены токенайзером (например, методом BPE). Длина контекста модели измеряется в токенах.

Вопрос: Что такое трансформер?
Ответ: Архитектура нейросети, представленная в 2017 году в статье «Attention Is All You Need». Её ключевая идея — механизм внимания, позволяющий каждому токену учитывать другие токены текста. На трансформерах построены современные языковые модели.

Вопрос: Что значит GPT?
Ответ: Generative Pre-trained Transformer: порождающий предобученный трансформер. Это класс языковых моделей, которые сначала предобучаются на больших текстах, а затем настраиваются под задачи.

Вопрос: Что такое галлюцинация модели?
Ответ: Случай, когда языковая модель уверенно выдаёт неправильную или выдуманную информацию. Причина: модель предсказывает правдоподобный текст, а не проверяет истину. Снизить риск помогают подключение источников (RAG), проверка ответов и честное «не знаю».

Вопрос: Что такое RAG?
Ответ: Retrieval-Augmented Generation: сначала система ищет в базе знаний нужные фрагменты, затем передаёт их языковой модели как контекст, и модель отвечает на их основе. Так ответы точнее и опираются на проверенные данные.

Вопрос: Что такое эмбеддинг?
Ответ: Числовой вектор, который представляет смысл слова, фразы или документа. Близкие по смыслу тексты имеют близкие векторы, поэтому по ним можно искать по смыслу, а не только по совпадению слов.

Вопрос: Что такое дообучение (fine-tuning)?
Ответ: Продолжение обучения уже обученной модели на небольшом наборе данных под конкретную задачу или стиль. Требует меньше ресурсов, чем обучение с нуля, но зависит от лицензии базовой модели.

Вопрос: Что такое квантование модели?
Ответ: Уменьшение точности чисел, в которых хранятся веса (например, с 16 бит до 4 бит). Модель занимает меньше памяти и быстрее работает на слабых устройствах, но качество может немного упасть.

Вопрос: Зачем для обучения нужны видеокарты (GPU)?
Ответ: В обучении нейросетей миллионы одинаковых операций над числами. Видеокарта выполняет множество таких операций параллельно, поэтому в десятки раз быстрее обычного процессора.

Вопрос: Что такое параметры модели?
Ответ: Это обучаемые числа (веса) внутри сети. «Модель на 1 миллиард параметров» значит около миллиарда таких чисел. Больше параметров обычно даёт больше возможностей, но требует больше памяти и данных.

Вопрос: Что такое тест Тьюринга?
Ответ: Идея Алана Тьюринга (1950): если человек в переписке не может отличить машину от человека, то можно говорить, что машина демонстрирует интеллектуальное поведение. Тест вызывает споры, это не строгая мера интеллекта.

Вопрос: Когда появился термин «искусственный интеллект»?
Ответ: Термин предложил Джон Маккарти для летнего семинара в Дартмуте в 1956 году. Эту встречу часто считают началом ИИ как научной области.

Вопрос: Почему маленькая модель, обученная с нуля на малом объёме текста, получается слабой?
Ответ: Языковая модель выучивает закономерности из данных. Если параметров мало и текста мало (мегабайты вместо сотен гигабайт), она запоминает фразы, плохо обобщает, путает факты и часто пишет бессвязный текст. Качество зависит от трёх вещей: размера модели, объёма и качества данных, вычислительных ресурсов.

Вопрос: Какие этические проблемы связаны с ИИ?
Ответ: Смещения и предвзятость в данных, приватность личных данных, авторские права на обучающие тексты, дезинформация и deepfake, ответственность за ошибки системы, влияние на рабочие места. Поэтому важны проверка данных и прозрачность.

==================================================
РАЗДЕЛ 11. ЛОГИКА И КРИТИЧЕСКОЕ МЫШЛЕНИЕ
==================================================

Вопрос: Что такое логические операции И, ИЛИ, НЕ?
Ответ: И (конъюнкция) истинно только если истинны оба утверждения. ИЛИ (дизъюнкция) истинно, если истинно хотя бы одно. НЕ (отрицание) меняет истину на ложь. Пример: «идёт дождь И у меня есть зонт» истинно только когда выполнено оба условия.

Вопрос: Что такое импликация «если..., то...»?
Ответ: Утверждение «если A, то B» ложно только в одном случае: когда A истинно, а B ложно. Если A ложно, импликация считается истинной. Пример: «Если число делится на 4, то оно чётное» верно, но обратное «если число чётное, то оно делится на 4» неверно.

Вопрос: Чем отличаются дедукция, индукция и абдукция?
Ответ: Дедукция идёт от общего к частному и при верных посылках даёт верный вывод. Индукция идёт от частных случаев к общему выводу и даёт вероятный результат. Абдукция подбирает лучшее объяснение наблюдаемым фактам (так рассуждает врач или следователь).

Вопрос: Что такое силлогизм?
Ответ: Вывод из двух посылок. Классический пример: «Все люди смертны. Сократ человек. Значит, Сократ смертен». Вывод верен, если посылки истинны и форма правильна.

Вопрос: Что такое логическая ошибка «ad hominem»?
Ответ: Критика человека вместо критики его аргумента. Пример: «Ты ничего не понимаешь в математике, поэтому твоя теорема неверна». Правильность довода не зависит от личности говорящего.

Вопрос: Что такое «ложная дилемма»?
Ответ: Ошибка, когда предлагаются только два варианта, хотя на самом деле их больше. Пример: «Либо ты со мной, либо против меня».

Вопрос: Что такое «соломенное чучело»?
Ответ: Искажение чужой позиции, чтобы её было легче опровергнуть. Вместо настоящего аргумента оппонента критикуют упрощённую или преувеличенную версию.

Вопрос: Чем корреляция отличается от причинности?
Ответ: Корреляция означает, что две величины меняются вместе. Это не доказывает, что одна вызывает другую. Классический пример: продажи мороженого и число случаев утопления растут летом одновременно, но причина общая — жаркая погода.

Вопрос: Что такое ошибка «после этого значит по причине этого»?
Ответ: Ошибка post hoc: считать, что если событие B произошло после события A, то A его вызвало. Пример: «Я надел носки, и мне повезло на экзамене».

Вопрос: Что такое апелляция к авторитету?
Ответ: Довод вида «это правда, потому что так сказал известный человек». Мнение эксперта в его области весомо, но не заменяет доказательств, особенно если он говорит не о своей специальности.

Вопрос: Что такое круг в доказательстве?
Ответ: Ошибка, когда вывод уже содержится в посылке. Пример: «Эта книга правдива, потому что в ней написано, что она правдива».

Вопрос: Что такое подтверждающее искажение?
Ответ: Склонность искать и запоминать то, что подтверждает уже имеющееся мнение, и не замечать противоположные факты. Помогает сознательный поиск аргументов против своей точки зрения.

Вопрос: Как проверить достоверность информации?
Ответ: Посмотреть, кто автор и какой источник. Найти подтверждение в независимых надёжных источниках. Проверить дату. Отделить факты от мнений. Обратить внимание на эмоциональные заголовки. Найти первоисточник данных, а не пересказ.

Вопрос: Что такое бритва Оккама?
Ответ: Принцип: не следует множить сущности без необходимости. Из нескольких объяснений, одинаково хорошо описывающих факты, лучше выбрать самое простое. Это эвристика, а не закон.

Вопрос: Что такое парадокс лжеца?
Ответ: Высказывание «это утверждение ложно». Если оно истинно, то оно ложно, а если ложно — то истинно. Такие самоссылающиеся утверждения показывают границы наивной логики.

Вопрос: Что такое парадокс Монти Холла?
Ответ: Есть три двери, за одной приз. Вы выбрали дверь, ведущий, зная, где приз, открывает другую дверь без приза и предлагает поменять выбор. Лучше поменять: вероятность выигрыша становится 2/3, а при сохранении выбора остаётся 1/3.

Вопрос: Остров рыцарей и лжецов: рыцари всегда говорят правду, лжецы всегда лгут. Встречный говорит «Я лжец». Кто он?
Ответ: Такое сказать не может никто. Рыцарь не скажет о себе неправду, а лжец, назвав себя лжецом, сказал бы правду. Значит, ситуация невозможна.

Вопрос: Что тяжелее: килограмм пуха или килограмм железа?
Ответ: Одинаково. Оба весят килограмм, различается только объём.

Вопрос: Сколько месяцев в году имеют 28 дней?
Ответ: Все двенадцать: в каждом месяце есть 28 дней (в одних больше, но 28 есть в каждом).

Вопрос: У вас в комнате три яблока, вы забрали два. Сколько яблок у вас?
Ответ: Два, потому что именно столько вы взяли.

Вопрос: Два отца и два сына поймали три рыбы, и каждому досталось по одной. Как это возможно?
Ответ: Рыбаков трое: дед, его сын и внук. Дед и сын — два отца, сын и внук — два сына.

Вопрос: Две монеты в сумме дают 15 копеек, одна из них не пятак. Какие это монеты?
Ответ: Пятак и гривенник (5 и 10 копеек). Не пятак — именно гривенник, а вторая монета как раз пятак.

Вопрос: Как за один заход в комнату определить, какой из трёх выключателей включает лампу, если лампы из коридора не видно?
Ответ: Включить первый выключатель на несколько минут, затем выключить его и включить второй. Войти в комнату. Если лампа горит — это второй выключатель. Если не горит, но тёплая — первый. Если холодная и не горит — третий.

Вопрос: Как перевезти через реку волка, козу и капусту, если лодка берёт одного пассажира и нельзя оставлять волка с козой и козу с капустой?
Ответ: Перевезти козу. Вернуться. Перевезти волка, забрать козу обратно. Перевезти капусту, вернуться. Перевезти козу. Так никто никого не съест.

Вопрос: Старик имеет пять дочерей: Чача, Чеча, Чича, Чоча. Как зовут пятую?
Ответ: Чуча. Гласные в именах идут по порядку: а, е, и, о, а пятая получает у.

Вопрос: Как рассуждать, если нужно принять сложное решение?
Ответ: Чётко сформулировать цель, перечислить варианты, выписать плюсы и минусы каждого, оценить риски и последствия, собрать недостающие факты и учесть, что можно будет отменить, а что нельзя. Полезно поговорить с человеком, который смотрит на ситуацию по-другому.

РАЗДЕЛ 12. РУССКИЙ ЯЗЫК
==================================================

Вопрос: Сколько букв и звуков в русском алфавите?
Ответ: В алфавите 33 буквы: 10 гласных (а, о, у, ы, э, я, ю, е, ё, и), 21 согласная и две буквы (ь и ъ), которые не обозначают звуков. Алфавит основан на кириллице, созданной в IX веке на основе трудов Кирилла и Мефодия и их учеников.

Вопрос: Какие бывают части речи в русском языке?
Ответ: Самостоятельные: существительное, прилагательное, числительное, местоимение, глагол, наречие. Служебные: предлог, союз, частица. Отдельно стоит междометие. Причастие и деепричастие считаются особыми формами глагола.

Вопрос: Какие падежи есть в русском языке?
Ответ: Шесть: именительный (кто? что?), родительный (кого? чего?), дательный (кому? чему?), винительный (кого? что?), творительный (кем? чем?), предложный (о ком? о чём?).

Вопрос: Какие есть роды существительных?
Ответ: Мужской (стол, отец), женский (книга, мама) и средний (окно, море). Род определяют по согласованию слов: «мой стол», «моя книга», «моё окно».

Вопрос: Как пишутся сочетания жи-ши, ча-ща, чу-щу?
Ответ: После ж и ш пишется буква и (жизнь, шипеть), после ч и щ пишется а (чайка, роща), после ч и щ пишется у (чудо, щука). Исключения встречаются в заимствованных словах и фамилиях.

Вопрос: Когда писать -тся и когда -ться в глаголах?
Ответ: Нужно задать вопрос к глаголу. Если вопрос «что делает?» или «что сделает?» — пишется -тся (учится, вернётся). Если вопрос «что делать?» или «что сделать?» — пишется -ться (учиться, вернуться).

Вопрос: Как проверить безударную гласную в корне?
Ответ: Нужно изменить слово или подобрать однокоренное так, чтобы гласная оказалась под ударением. Например: вода — воды, гора — горы, леса — лес (в проверочных словах ударение падает на нужную гласную).

Вопрос: Как писать не с глаголами?
Ответ: Обычно раздельно: не читать, не знаю, не пойду. Слитно, если слово без не не употребляется: ненавидеть, негодовать.

Вопрос: Чем отличаются приставки при- и пре-?
Ответ: При- обозначает приближение, присоединение, неполноту действия: приехать, прикрепить, приоткрыть. Пре- обозначает высокую степень или значение «через»: премилый, преодолеть, преграда. Иногда нужно учить исключения.

Вопрос: Как определить спряжение глаголов?
Ответ: Нужно взять безударное окончание и привести глагол в неопределённую форму. Ко II спряжению относятся глаголы на -ить (кроме брить и стелить) и 7 глаголов на -еть: смотреть, видеть, обидеть, ненавидеть, зависеть, терпеть, вертеть, а также 4 на -ать: гнать, держать, дышать, слышать. Остальные глаголы — I спряжение.

Вопрос: Каковы окончания спряжений в настоящем времени?
Ответ: I спряжение: -ешь, -ет, -ем, -ете, -ут/-ют. II спряжение: -ишь, -ит, -им, -ите, -ат/-ят. Примеры: читаешь, читает (I); говоришь, говорит (II).

Вопрос: Что такое грамматическая основа предложения?
Ответ: Подлежащее и сказуемое. Подлежащее отвечает на вопрос «кто? что?», сказуемое — на вопрос «что делает?». Остальные члены предложения второстепенные: определение (какой?), дополнение (кого? что?), обстоятельство (где? когда? как?).

Вопрос: Когда ставится запятая при однородных членах?
Ответ: Между однородными членами без союза ставят запятую: «Мы купили хлеб, молоко, сыр». Перед союзом но, а, зато запятая нужна всегда. Перед одиночным и запятая не нужна: «хлеб и молоко». Запятые нужны также при обращениях и вводных словах.

Вопрос: Как поставить правильное ударение в частых словах?
Ответ: Нужно запомнить: звонИт, включИт, красИвее, тОрты, договОр, квартАл, срЕдства, балОвать, шАрфы. Остальные случаи проверяют по орфоэпическому словарю.

Вопрос: Что такое синонимы, антонимы и омонимы?
Ответ: Синонимы — слова с близким значением (большой — огромный). Антонимы — слова с противоположным значением (добрый — злой). Омонимы — слова с одинаковым написанием или звучанием, но разным значением (лук — овощ и лук — оружие).

Вопрос: Как правильно: одеть или надеть?
Ответ: Надевают что-то на себя или на кого-то (надеть куртку, надеть шапку на ребёнка). Одевают кого-то (одеть ребёнка, одеть куклу). Запомнить: «одеть Надежду, надеть одежду».

Вопрос: Из каких частей состоит слово?
Ответ: Корень (главная часть, общая для родственных слов), приставка (перед корнем), суффикс (после корня), окончание (изменяемая часть, показывает форму). Основа слова — часть без окончания.

Вопрос: Какие стили речи различают?
Ответ: Разговорный, научный, официально-деловой, публицистический и художественный. Выбор стиля зависит от цели и ситуации общения.

Вопрос: Как построить связный текст?
Ответ: Определить тему и главную мысль, составить план, дать вступление, основную часть с аргументами и примерами, заключение. Каждая мысль начинается с новой строки, предложения связываются по смыслу, повторы убираются.

РАЗДЕЛ 13. ТАДЖИКСКИЙ ЯЗЫК (ЗАБОНИ ТОҶИКӢ)
==================================================

Вопрос: Что за язык таджикский?
Ответ: Таджикский язык (забони тоҷикӣ) относится к иранской группе индоевропейской семьи и родственен персидскому языку Ирана (фарси) и дари Афганистана. Это государственный язык Таджикистана. Пишут на кириллице, а в Иране и Афганистане родственные языки пишут арабским письмом.

Вопрос: Сколько букв в таджикском алфавите?
Ответ: 35 букв: А, Б, В, Г, Ғ, Д, Е, Ё, Ж, З, И, Ӣ, Й, К, Қ, Л, М, Н, О, П, Р, С, Т, У, Ӯ, Ф, Х, Ҳ, Ч, Ҷ, Ш, Ъ, Э, Ю, Я. Особые буквы: Ғ, Ӣ, Қ, Ӯ, Ҳ, Ҷ.

Вопрос: Как по-таджикски «привет», «спасибо», «пожалуйста»?
Ответ: Салом — привет, здравствуйте. Раҳмат или ташаккур — спасибо. Лутфан — пожалуйста (при просьбе). Бубахшед — извините. Хайр или Худоҳофиз — до свидания.

Вопрос: Как по-таджикски «да» и «нет»?
Ответ: «Да» — бале или ҳа. «Нет» — не. Для отрицания глагола добавляется приставка на-: намехонам — я не читаю.

Вопрос: Как пожелать доброго утра, дня и спокойной ночи по-таджикски?
Ответ: Субҳ ба хайр — доброе утро. Рӯз ба хайр — добрый день. Шом ба хайр — добрый вечер. Шаб ба хайр — спокойной ночи. Хуш омадед — добро пожаловать.

Вопрос: Как по-таджикски «Как вас зовут?» и «Меня зовут...»?
Ответ: Номи шумо чист? — Как вас зовут? Номи ман Али аст — Меня зовут Али. Также можно спросить «Шумо кистед?» — Кто вы?

Вопрос: Как спросить «Как дела?» по-таджикски?
Ответ: Ҳоли шумо чӣ хел? или Аҳволатон чӣ хел? Ответ: Хуб, ташаккур — Хорошо, спасибо. Бад нест — неплохо.

Вопрос: Как по-таджикски сказать «Я из Таджикистана»?
Ответ: Ман аз Тоҷикистон ҳастам. «Откуда вы?» — Шумо аз куҷо ҳастед?

Вопрос: Как считать до десяти по-таджикски?
Ответ: Як (1), ду (2), се (3), чор (4), панҷ (5), шаш (6), ҳафт (7), ҳашт (8), нӯҳ (9), даҳ (10). Далее: бист (20), сӣ (30), чил (40), панҷоҳ (50), сад (100), ҳазор (1000).

Вопрос: Как называются дни недели по-таджикски?
Ответ: Душанбе — понедельник, сешанбе — вторник, чоршанбе — среда, панҷшанбе — четверг, ҷумъа — пятница, шанбе — суббота, якшанбе — воскресенье. Название столицы Душанбе значит «понедельник»: на этом месте был базар по понедельникам.

Вопрос: Как называются члены семьи по-таджикски?
Ответ: Падар — отец, модар — мать, бародар — брат, хоҳар — сестра, писар — сын, духтар — дочь, бобо — дедушка, бибӣ — бабушка, ӯ — он или она, оила — семья.

Вопрос: Какие вопросительные слова есть в таджикском?
Ответ: Чӣ — что, кӣ — кто, куҷо — где или куда, кай — когда, чаро — почему, чанд — сколько, кадом — какой. Пример: Ин чист? — Что это? Шумо куҷо меравед? — Куда вы идёте?

Вопрос: Какие личные местоимения есть в таджикском языке?
Ответ: Ман — я, ту — ты, ӯ — он или она (рода нет), мо — мы, шумо — вы, онҳо — они. Вежливое обращение к одному человеку тоже «шумо».

Вопрос: Есть ли в таджикском языке род и артикли?
Ответ: Нет. Грамматического рода в таджикском языке нет, артиклей тоже. Слова «он» и «она» передаются одним местоимением ӯ.

Вопрос: Как в таджикском образуется множественное число?
Ответ: Обычно добавляют -ҳо: китоб — китобҳо (книги), мактаб — мактабҳо (школы). Для людей часто используют -он: духтар — духтарон (девочки), муаллим — муаллимон (учителя).

Вопрос: Как в таджикском выражается принадлежность (изафет)?
Ответ: С помощью изафета: к определяемому слову добавляется -и, а определение стоит после него. Примеры: китоби ман — моя книга; мактаби калон — большая школа; хонаи бобо — дом дедушки. Также используют суффиксы: китобам — моя книга, китобат — твоя книга, китобаш — его книга.

Вопрос: Какой порядок слов в таджикском предложении?
Ответ: Обычно подлежащее, дополнение, сказуемое: Ман китоб мехонам — Я читаю книгу (буквально «я книгу читаю»). Глагол стоит в конце предложения.

Вопрос: Как спрягается глагол «быть» (ҳастан) в настоящем времени?
Ответ: Ман ҳастам, ту ҳастӣ, ӯ аст, мо ҳастем, шумо ҳастед, онҳо ҳастанд. Пример: Ман донишҷӯ ҳастам — Я студент. Ӯ муаллим аст — Он учитель.

Вопрос: Как спрягается глагол в настоящем времени на примере «хондан» (читать)?
Ответ: Приставка ме- плюс основа хон плюс личное окончание: ман мехонам, ту мехонӣ, ӯ мехонад, мо мехонем, шумо мехонед, онҳо мехонанд. Отрицание: ман намехонам.

Вопрос: Как образуется прошедшее и будущее время?
Ответ: Прошедшее: основа прошедшего времени плюс окончание: ман хондам — я прочитал, ту хондӣ, ӯ хонд. Будущее: вспомогательный глагол хоҳам плюс краткая форма глагола: ман хоҳам хонд — я прочитаю.

Вопрос: Как по-таджикски «Я иду в школу»?
Ответ: Ман ба мактаб меравам. Глагол рафтан (идти) имеет основу рав: меравам, меравӣ, меравад, меравем, меравед, мераванд.

Вопрос: Как называются цвета по-таджикски?
Ответ: Сафед — белый, сиёҳ — чёрный, сурх — красный, кабуд — синий или голубой, сабз — зелёный, зард — жёлтый, норанҷӣ — оранжевый, хокистарӣ — серый.

Вопрос: Как по-таджикски «вода», «хлеб», «чай»?
Ответ: Об — вода, нон — хлеб, чой — чай, шир — молоко, гӯшт — мясо, мева — фрукты, себ — яблоко, ангур — виноград. «Я хочу воды» — Ман об мехоҳам.

Вопрос: Какие известные писатели писали на таджикско-персидском языке?
Ответ: Рудаки (X век), Абулқасим Фирдоуси (автор «Шахнаме», около 1010 года), Омар Хайям, Саъдӣ, Ҳофиз, Джалаледдин Руми. Из современных авторов: Садриддин Айни (1878–1954), основатель современной таджикской литературы, и Мирзо Турсунзаде.

Вопрос: Чем таджикский язык отличается от персидского языка Ирана?
Ответ: Языки очень близки и во многом взаимно понятны, но различаются письмом (кириллица и арабская графика), произношением, частью лексики (в таджикском больше русских заимствований, в персидском больше арабских) и отдельными грамматическими формами.

Вопрос: Какие фразы полезны для знакомства по-таджикски?
Ответ: Салом, номи ман Али аст — Здравствуйте, меня зовут Али. Аз шиносоӣ бо шумо хурсандам — Рад знакомству с вами. Шумо бо забони русӣ ҳарф мезанед? — Вы говорите по-русски? Ман тоҷикӣ меомӯзам — Я изучаю таджикский.
